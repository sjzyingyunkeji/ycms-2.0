## 二、差距浓缩：YCMS 领先什么、输什么

### YCMS 明确领先的 7 项（对比上述四款）

| 能力 | 为什么领先 |
| --- | --- |
| 零配置部署 | 唯一不用伪静态/重写规则即可跑完整站点（API 走 `/api.php/...` 真实文件） |
| 静态化混合渲染 | 静态直出 + SSR 兜底 + SPA 三层组合，没有第二家 PHP CMS 这样做 |
| 安全基线 | 默认口令门禁、nonce 防重放、DOMPurify、三重上传校验、IP 哈希全部内置 |
| 内置访问统计 | PV/UV/来源/设备/蜘蛛全套，且隐私合规，不用外部服务 |
| 运维闭环 | 在线升级六步链 + 签名校验 + 备份回滚 + 自动迁移，一步不缺 |
| 结构化数据 SEO | JSON-LD（BlogPosting + BreadcrumbList）服务端直出，竞品普遍需插件 |
| 前后台故障隔离 | 两套独立构建，前台构建失败不影响后台可用 |

### YCMS 落后最多的 6 项（决定能否承接内容型站点）

| 缺失能力 | 输给谁 | 影响等级 |
| --- | --- | --- |
| 自定义内容模型+字段 | PbootCMS | **致命**（做不了企业产品站） |
| 无限极分类 | PbootCMS、WordPress | 高 |
| 多用户+角色权限 | WordPress、Typecho、Emlog | 高 |
| 自定义表单+邮件通知 | PbootCMS | 高（企业站刚需） |
| 全文搜索/多条件筛选 | PbootCMS | 中 |
| 多语言站点 | PbootCMS | 中（看定位，可选） |

**一句话总结**：YCMS 在**部署成本、静态性能、安全基线、运维体验**上是同场景最强；在**内容模型自由度、多人协作、企业站功能覆盖**上是明显短板，因此当前只适合「单人运营、内容形态固定」的站点。

## 三、选型决策速查

| 你的需求 | 直接选 |
| --- | --- |
| 低配主机 + 个人博客 + 要 SEO 和统计开箱即用 | **YCMS ✅** |
| 企业官网要产品/案例/下载等多种内容类型 | PbootCMS |
| 要商城、会员、表单、多作者协作 | WordPress |
| 只想极简写博客 / 小团队分级写作 | Typecho / Emlog Pro |
