用 Vue 3 组合式 API 组织前端代码

技术随笔 2026-10-25 0 次阅读 @星尘管理员

组合式 API 的魅力

Vue 3 的组合式 API 让我们可以按功能逻辑组织代码，而不是按选项类型拆分。

<script setup>
import { ref, computed } from 'vue'

const count = ref(0)
const double = computed(() => count.value * 2)
</script>

与 React Hooks 的区别

  • 组合式函数的 setup 只执行一次，不存在闭包陷阱
  • 没有 Hook 的顺序调用规则
  • TypeScript 类型推断更友好

实战建议

  1. 将可复用逻辑抽取为 useXxx 组合式函数
  2. 使用 Pinia 管理跨组件状态
  3. 合理拆分组件，保持单一职责
