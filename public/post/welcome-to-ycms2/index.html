关于 ycms2.0

ycms2.0 是一个轻量而完整的个人内容管理系统，采用以下技术栈构建：

  • 后端：PHP 8.2+（严格类型、枚举、只读属性等现代特性）
  • 前端：Vue 3 + Vite + Tailwind CSS
  • 数据库：SQLite（零配置，WAL 模式）
  • 风格：星空星光主题 + 玻璃拟态设计

主要功能

  1. 文章管理（Markdown 编辑器、草稿/发布、置顶）
  2. 分类与标签管理
  3. 独立页面管理
  4. 媒体库（图片上传）
  5. 评论审核
  6. 友链管理
  7. 站点设置
  8. 仪表盘统计

快速上手

登录后台后，你可以在「文章」中创建你的第一篇内容。所有内容都支持 Markdown 语法。

星空之所以美丽，是因为每一颗星星都在自己的位置上闪耀。

// PHP 8.2+ 示例
enum PostStatus: string {
    case Draft = 'draft';
    case Published = 'published';
}
